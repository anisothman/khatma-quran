# 📖 ختمة القرآن الكريم

منصة ويب بسيطة لمتابعة ختمة القرآن الكريم بشكل جماعي، حيث يمكن لكل مشارك معرفة الأحزاب المخصصة له وتسجيل إتمام القراءة، بينما يستطيع المشرف متابعة تقدم المجموعة وإدارة المشاركين والختمات.

## ✨ مميزات المشروع

### 👤 للمشاركين
- عرض رقم الأسبوع الحالي.
- عرض الأحزاب المطلوبة للقراءة.
- اختيار اسم المشارك.
- عرض الأحزاب الخاصة بكل مشارك.
- تسجيل إتمام الحزبين.
- معرفة حالة جميع المشاركين.
- عرض نسبة الإنجاز الإجمالية.
- تحديث البيانات بشكل مباشر.

### 🔐 للمشرف
- تسجيل الدخول بحساب المشرف.
- متابعة المشاركين الذين أتموا القراءة.
- متابعة المشاركين الذين لم يتموا القراءة.
- الانتقال إلى الختمة التالية.
- العودة إلى الختمة السابقة.
- إعادة ضبط حالات الأسبوع الحالي.
- استبدال مشارك بمشارك آخر مع الحفاظ على مكانه وبياناته.
- متابعة الأحزاب الخاصة بكل مشارك.
- الاحتفاظ بتاريخ الإتمام لكل أسبوع.

## 📚 نظام الأحزاب

يتم توزيع الأحزاب على المشاركين بالتتابع:

1. 1 / 2
2. 3 / 4
3. 5 / 6
4. 7 / 8
5. ...
6. 57 / 58
7. 59 / 60

بعد الحزبين 59 و60 تبدأ الدورة من جديد:

`1 / 2`

## 🗂️ هيكلة المشروع

```text
khatma-quran/
│
├── index.html        # واجهة المشاركين
├── admin.html        # لوحة تحكم المشرف
├── style.css         # تصميم الموقع
├── database.sql      # إعداد قاعدة البيانات
└── README.md         # توثيق المشروع
🗄️ قاعدة البيانات

يعتمد المشروع على Supabase لإدارة البيانات.

الجداول الرئيسية:

participants
khatma_settings
week_completions
admins

ويستخدم المشروع عدة RPC Functions لإدارة العمليات الحساسة الخاصة بالمشرف.

🔒 الأمان

يستخدم المشروع:

Supabase Authentication للمشرف.
Row Level Security (RLS).
صلاحيات خاصة بعمليات المشرف.
التحقق من صلاحية المشرف داخل RPC Functions.

ملاحظة: مفتاح Supabase المستخدم في الواجهة يجب أن يكون فقط anon/publishable key.
لا يجب أبدًا وضع service_role أو أي Secret Key داخل ملفات Frontend.

🚀 تشغيل المشروع محليًا

يمكن تشغيل المشروع بسهولة باستخدام VS Code وLive Server.

قم بتحميل المشروع:
git clone https://github.com/USERNAME/khatma-quran.git
افتح المشروع في VS Code.
شغّل index.html باستخدام Live Server.
تأكد من إعداد Supabase ووجود الجداول والـ RPC Functions المطلوبة.
🌐 النشر

يمكن نشر المشروع باستخدام GitHub Pages.

بعد تفعيل GitHub Pages سيكون الموقع متاحًا عبر رابط مشابه:

https://USERNAME.github.io/khatma-quran/

وبذلك يمكن مشاركة الرابط مع جميع المشاركين والدخول إلى الموقع من الهاتف أو الحاسوب.

🎯 الهدف

يهدف المشروع إلى تسهيل تنظيم الختمة الجماعية للقرآن الكريم، وتقليل الحاجة إلى المتابعة اليدوية، مع توفير طريقة واضحة لمعرفة:

من قرأ؟
من لم يقرأ؟
ما الأحزاب المخصصة لكل مشارك؟
ما نسبة تقدم المجموعة؟
ما الختمة الحالية؟
